Uniform Shielded TEM Reference Line · Application view

Reflection and impedance

This Uniform Shielded TEM Reference Line view selects diagonal reflection S(2,2) at 5.500 GHz with the option “Smith: wavelength scales”. Readouts include Gamma, normalized input impedance and impedance in ohms with a 50 ohm reference. These are calculated port results, not a measurement or a general characteristic-impedance result.

Development preview. External validation is not yet complete. Not released for production use.

The outer wavelength scales are graphical aids for the displayed lossless-line convention. This application view does not show a separate line-length calculation or deembedding result. The marker frequency does not identify the frequency of the time-domain field slices.
