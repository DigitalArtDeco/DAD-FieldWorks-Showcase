# PCB 2D Microstrip Scientific Field Sequence

This directory contains a public-safe PNG frame sequence for the DAD FieldWorks
homepage hero animation.

The frames show a PCB 2D microstrip electric-field magnitude visualization using
the Scientific Field Image Renderer V2 style:

- blue-to-red scalar field colors,
- black ground depiction,
- green substrate boundary,
- dark signal trace overlay,
- numeric axes,
- colorbar,
- fixed 800 x 600 raster layout.

The frame values are derived from a real internal DAD FieldWorks PCB 2D
quasi-static field grid. The animation applies a deterministic drive voltage
amplitude envelope to the field magnitude while keeping the colorbar range fixed
across all frames.

This is an internal field visualization only. It is not a frequency sweep, not a
current sweep, not a time-domain wave propagation result, not a full wave
simulation, not external validation and not production evidence.
