# Dipole Current, Far Field, And Smith Chart

This animation shows a thin-wire dipole diagnostic with current distribution, far-field pattern, and a Smith chart impedance locus.

The model family is a thin-wire sinusoidal-current diagnostic approximation for a center-fed dipole. The current distribution is shown along the dipole wire with red indicating high current and blue indicating low current. The far-field panel is generated from the same normalized current model. The Smith chart is drawn with generated primitives from a reduced diagnostic impedance sweep around the nominal half-wave state, using `Z0 = 50 ohm`.

Rendered quantities:

- Current magnitude along the dipole.
- Normalized far-field pattern.
- Generated impedance locus and moving sweep marker on a Smith chart.
- Normalized frequency sweep from `f/f0 = 0.70` to `f/f0 = 1.30`.

No external images were used. No screenshots were used. No AI image generation was used. No private solver source code is published.

This is a diagnostic antenna visualization only. It is not validation evidence, not a production readiness claim, and not a commercial antenna solver equivalence claim.
