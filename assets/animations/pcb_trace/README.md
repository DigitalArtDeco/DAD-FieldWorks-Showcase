# PCB Trace Field Animation

This animation shows signed Ez field behavior around a PCB conductor trace with an open stub.

- Rendered quantity: signed Ez.
- Solver family: 2D FDTD TMz.
- Geometry: PCB trace and open stub represented as a PEC mask in a uniform effective dielectric substrate.
- Source: Gaussian-modulated sine soft point source.
- Boundary handling: graded loss layer with simple absorbing edge copy.
- Creation method: solver generated numerical field visualization.

- Screenshots: none.
- AI image generation: none.
