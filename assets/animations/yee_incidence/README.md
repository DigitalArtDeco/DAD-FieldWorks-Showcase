# Yee Curl Incidence Microprototype

This animation shows a public-safe diagnostic view of oriented Yee E unknowns
and signed curl incidence rows.

It visualizes the bounded native Yee curl incidence microprototype concept:
local E edge orientation, a curl loop orientation, plus and minus incidence
signs, a symbolic bounded row record, and a compact claim-boundary card.

The visualization is operator-near, but it is not a production operator. It is
not curl-curl assembly, not a matrix solver, and not an eigenmode solver. It
is not validation evidence and not a production readiness claim.

No external images were used. No screenshots were used. No AI image generation
was used. No private solver source code is published.
