# Eigenpair Residual Evidence Gate

This public showcase animation visualizes solver output as a claim that must
be checked before any claim promotion.

The animation shows:

1. A candidate eigenpair field slice.
2. A residual calculation using `r = A e - lambda M e`.
3. A computed residual magnitude.
4. A deterministic bounded evidence score.
5. A final claim gate.

The residual magnitude is computed, not invented. The evidence score is
formula based and bounded diagnostic only. If no public safe summary data is
used, the animation uses a public canonical rectangular PEC cavity scalar
candidate.

This animation is not a DAD production eigensolver output. It is not external
validation. It is not production readiness. It is not a commercial solver
equivalence claim. It is not a validated eigenmode claim. It is not a qubit
simulation.

No external images were used. No screenshots were used. No generative image
tools were used. No private source code is published.
