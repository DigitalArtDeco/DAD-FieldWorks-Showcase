# DAD FieldWorks Brand Assets

This folder contains public brand graphics for the DAD FieldWorks showcase site.

## Blue field sculpture

The current blue wire-mesh wave sculpture was explicitly requested by the user on 9 September 2026. It was created with the built-in image generation tool. It appears beside the company wordmark, in the DAD FieldWorks section and as the browser icon. It is abstract brand artwork, not scientific data or a solver result.

The full PNG is `dad_fieldworks_blue_field_sculpture.png`. The website uses the proportionally reduced `dad_fieldworks_blue_field_sculpture-256.png`. The browser icon contains 16, 32, 48 and 64 pixel versions. The [generation record](blue_field_sculpture_manifest.json) contains the full prompt and file hashes. The former browser icon is preserved as `legacy_kernel_wave_favicon.ico`. No application screenshot was altered by this artwork change.

## Historical Kernel Wave Mark

`dad_fieldworks_kernel_wave_mark.png` and `dad_fieldworks_kernel_wave_mark.svg`
are deterministic graphics derived from a public-safe rectangular PEC cavity
mode 111 scalar field specification.

Source field:

```text
E(x,z) = sin(pi x / a) sin(pi z / d)
a = 0.080 m
b = 0.084 m
d = 0.084 m
mode = 111
```

The graphics use no external images, no screen captures and no AI image
generation. They are public brand material only.

Claim boundary: bounded internal diagnostic visualization only. No external
validation claim. No production readiness claim. No commercial solver
equivalence claim.
