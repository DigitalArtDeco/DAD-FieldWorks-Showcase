# Public Whitepaper

This directory contains the current public whitepaper PDF for DAD FieldWorks.

[DAD FieldWorks Evidence Contract Architecture Whitepaper v0.9 public](DAD_FieldWorks_Evidence_Contract_Architecture_Whitepaper_v0_9_public.pdf)

Version 0.9 is formatted as a technical public specification draft for the evidence-controlled full-wave CEM solver platform direction. It reflects bounded internal alpha evidence paths, C++ Resonator Lab Alpha records, candidate eigenpair and residual diagnostics, residual threshold and analytical comparison gate record layers, and planning-only physical eigenpair acceptance gate direction.

It is not a validation report, not a product release, and not a commercial solver equivalence claim. It does not claim physical eigenpair acceptance execution, physical eigenfrequency acceptance, external validation or production readiness.

Previous public PDF versions remain available in this folder for history. The Markdown pages in `docs/` provide current public companion notes for status, claim boundaries, and roadmap context.
