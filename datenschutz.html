Allgemeine Hinweise

Die Unternehmenswebsite der DigitalArtDeco Labs UG (haftungsbeschränkt) ist vorübergehend pausiert. Unter www.dadlabs.de wird eine automatische Weiterleitung zum öffentlichen Showcase-Repository auf github.com bereitgestellt. Die deutschen und englischen Rechtstexte bleiben auf dieser Domain abrufbar. Diese Erklärung beschreibt die Verarbeitung beim Abruf der Weiterleitung und dieser Rechtstexte.

Hosting über GitHub Pages

Die öffentliche Website unter www.dadlabs.de wird über GitHub Pages bereitgestellt. Nach Angaben von GitHub wird beim Besuch einer über GitHub Pages bereitgestellten Website die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert. Daneben können technische Zugriffsdaten verarbeitet werden, die für die Bereitstellung und Sicherheit der Website, die Abwehr von Missbrauch oder die Fehleranalyse erforderlich sind. Dazu können Informationen über die Anfrage, das verwendete Gerät und die Nutzung gehören.

Die Verarbeitung dient dazu, diese Website sicher, stabil, technisch fehlerfrei und wirtschaftlich bereitzustellen und Missbrauch abzuwehren. Rechtsgrundlage auf Seiten der DigitalArtDeco Labs UG ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse besteht in der sicheren, zuverlässigen und wirtschaftlichen Bereitstellung dieses Angebots.

GitHub und technische Dienstleister oder Unterauftragnehmer von GitHub können die technischen Daten erhalten. Für diese Website ist nicht belegt, dass DigitalArtDeco Labs UG allgemein auf alle von GitHub geführten Protokolldaten zugreifen kann. Weitere Informationen enthält die GitHub General Privacy Statement.

Weiterleitung zu GitHub

Beim Aufruf der Startseite oder einer früheren Showcase-Unterseite lädt Ihr Browser zunächst die Weiterleitungsseite von GitHub Pages. Anschließend öffnet er automatisch das öffentliche Showcase-Repository auf github.com. Die Weiterleitung übermittelt keine URL-Parameter oder URL-Fragmente an das Ziel. Die Seite verwendet die Referrer-Richtlinie no-referrer.

Bereits der erste Abruf verursacht die oben beschriebene Hosting-Verarbeitung bei GitHub Pages. Die Weiterleitung unterbindet diese Verarbeitung nicht. Beim anschließenden Besuch von github.com verarbeitet GitHub Daten nach seinen eigenen Datenschutzinformationen und Cookieinformationen. Dort angebotene Cookie-Einstellungen werden von GitHub bereitgestellt und nicht von dieser Weiterleitungsseite gesteuert.

Cookies und technische Gestaltung während der Pause

Die Weiterleitung und die auf dieser Domain abrufbaren Rechtstexte setzen keine neuen dauerhaften Cookies und verwenden keine Analyse- oder Werbetracker. Es werden keine externen Schriftdateien, Bilder, Videos, Karten oder sozialen Plugins eingebunden. Es gibt kein Kontaktformular. Die Gestaltung ist direkt in den HTML-Dateien enthalten; Schriftarten stammen vom Gerät des Besuchers.

Der zuvor angebotene optionale Cookie __Host-dadlabs_notice wird nicht mehr verwendet. Beim Aufruf dieser Seiten versucht ein kurzes Skript, ausschließlich diesen Cookie auf dem aktuellen Host durch eine abgelaufene Cookie-Zuweisung zu löschen. Es speichert keine neue Präferenz und liest keinen Cookie-Inhalt aus. Ohne JavaScript kann ein früher gesetzter Cookie bis zu seinem ursprünglichen Ablauf bestehen bleiben und weiterhin vom Browser an den Host übermittelt werden. Er kann jederzeit über die Website-Dateneinstellungen des Browsers gelöscht werden.

Es wird keine Cookie-Einwilligung mehr abgefragt. Die Verarbeitung zur Bereitstellung und Absicherung der Weiterleitungs- und Rechtstextseiten bleibt davon unabhängig. Informationen über die IP-Protokollierung enthält die GitHub-Pages-Dokumentation.
