Diese Website stellt öffentliche Informationen zum Projekt DAD FieldWorks bereit. DAD FieldWorks ist ein privates Forschungs- und Entwicklungsprojekt.

Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können technische Zugriffsdaten verarbeitet werden. GitHub kann insbesondere IP-Adresse, Datum und Uhrzeit der Anfrage, aufgerufene Seiten, Browser- und Geräteinformationen sowie technische Nutzungsdaten verarbeiten.

GitHub gibt an, dass beim Besuch einer GitHub Pages Website die IP-Adresse des Besuchers aus Sicherheitsgründen protokolliert und gespeichert wird. Weitere Informationen enthält die GitHub Privacy Statement.

Rechtsgrundlage

Die Verarbeitung technisch erforderlicher Zugriffsdaten erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der sicheren, stabilen und fehlerfreien Bereitstellung dieser Website.

Keine eigenen Cookies, kein Tracking, keine Analytics

Diese Website setzt nach aktuellem Stand keine eigenen Cookies. Diese Website verwendet keine eigenen Analyse- oder Trackingdienste. Diese Website verwendet keine externen Schriftarten. Diese Website bindet keine externen Videos, Karten oder Social-Media-Plugins ein.
