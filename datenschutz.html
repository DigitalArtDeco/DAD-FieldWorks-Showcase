Die Verarbeitung dient dazu, diese Website sicher, stabil, technisch fehlerfrei und wirtschaftlich bereitzustellen und Missbrauch abzuwehren. GitHub und technische Dienstleister oder Unterauftragnehmer von GitHub können die technischen Daten erhalten.
