Allgemeine Hinweise

Diese Website ist der offizielle öffentliche DAD FieldWorks Showcase von DigitalArtDeco Labs UG (haftungsbeschränkt). Sie stellt öffentliche Informationen zum Produkt, zu ausgewählten Engineering-Funktionen und zu deren dokumentierten Nachweisen bereit. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Nach Angaben von GitHub wird beim Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert. Darüber hinaus können technische Zugriffsdaten, insbesondere Anfrage-, Geräte- und Nutzungsinformationen, verarbeitet werden, soweit dies für die Bereitstellung, Sicherheit, Missbrauchsabwehr und Fehleranalyse erforderlich ist.

Die Verarbeitung dient der sicheren, stabilen, technisch fehlerfreien und wirtschaftlichen Bereitstellung der Unternehmens- und Produktwebsite sowie der Abwehr von Missbrauch. Rechtsgrundlage auf Seiten der DigitalArtDeco Labs UG ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse besteht in der sicheren, zuverlässigen und wirtschaftlichen Bereitstellung dieses Angebots.

Empfänger der technischen Daten können GitHub und von GitHub eingesetzte technische Dienstleister oder Unterauftragnehmer sein. Ein allgemeiner Zugriff der DigitalArtDeco Labs UG auf sämtliche von GitHub geführten Protokolldaten ist für diese Website nicht belegt. Daten aus Kontaktanfragen werden gelöscht, sobald die Anfrage abschließend bearbeitet ist und keine weitere Speicherung für einen Vertrag, eine gesetzliche Aufbewahrungspflicht oder die Geltendmachung, Ausübung oder Verteidigung von Rechtsansprüchen erforderlich ist.
