Explicit material definitions

Materials stay with the project.

Use canonical PEC and lossless dielectric definitions, manage your own materials and retain project-bound material snapshots.

The supported dielectric definitions are scalar, isotropic and nondispersive. The library is not a manufacturer database and does not imply supplied copper-loss or roughness models.

Traceable work

Know which inputs a result belongs to.

Current means input-matched

The application marks results as current when they match the project inputs. A simulation-relevant input change makes existing results stale and blocks their export until a new matching calculation is available. This status is not a validation certificate.

Save and reopen

Retain project data, result references and viewer selections. Reopen matching saved results without rerunning the solver when their saved job data remains available.

Export within scope

Touchstone export supports complete, valid single-terminal TEM or quasi-TEM results with one channel per physical port and a common, constant positive real reference impedance. Coupled multimode datasets are outside this export scope.
