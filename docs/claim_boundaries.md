## Supported Capability Scope

- DAD-owned full-vector 3D time-domain electromagnetic core based on the staggered Yee method.
- Native Ex, Ey, Ez, Hx, Hy and Hz storage with explicit leapfrog field updates.
- Component-native material mapping, electric PEC enforcement, source coupling and material-aware CPML infrastructure.
- Native field snapshots and native two-port voltage and current acquisition.
- Yee-aware temporal alignment, deterministic direct Fourier transformation and real-reference power-normalized pseudowaves.
- Structured one-port and two-port RF processing with diagnostics for supported result datasets.
- Versioned complex S-parameter model and native Matrix, Cartesian and Smith-chart result views.
- Native wxWidgets desktop integration with embedded VTK scientific visualization.
- Component-native scalar slices and derived vector presentation modes with explicit source placement and provenance.
- Lossless two-conductor quasi-TEM cross-section foundations with residual, convergence, finite-value and physical-consistency diagnostics.
- Versioned, immutable evidence packages, process journals, evaluation records and fail-closed claim boundaries.

## Internally Exercised Reference Scope

The public numerical metrics refer to one accepted PCB reference execution: 4,096 transient steps, five saved full-vector field states and two raw Port V/I traces with 4,096 samples each. These values describe that reference execution rather than a universal product performance measure.

The public Canonical-Yee captures show saved states 2/5, 3/5, 4/5 and 5/5. Each capture uses the same Z-oriented slice and quantitative V/m scale.

## Publication Rule

Each public capability must remain within its verified class: implemented, focused-tested, internally exercised reference case, scientific visualization implemented, evidence architecture implemented or Result Workbench implemented.

Public wording stays within the accepted scope of each recorded reference result. New scientific or commercial assertions require their own accepted evidence before publication.
