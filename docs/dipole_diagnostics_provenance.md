# Dipole Diagnostics Provenance

The dipole diagnostics animation is generated from numerical antenna diagnostic data.

- Solver or model family: thin-wire sinusoidal-current diagnostic approximation.
- Dipole geometry summary: center-fed thin wire in free space, represented as a normalized one-dimensional conductor.
- Current model: sinusoidal current distribution with current maximum near the feed and current approaching zero near the wire ends.
- Far-field model: normalized far-field pattern generated from the same thin-wire diagnostic current model.
- Impedance or Smith chart model: reduced diagnostic impedance sweep around the nominal half-wave state, converted to reflection coefficient with a `50 ohm` reference impedance.
- Frequency sweep: normalized frequency sweep from `f/f0 = 0.70` to `f/f0 = 1.30`.
- Claim boundary: diagnostic visualization only, not validation evidence, not production readiness, and no commercial solver equivalence.

- Screenshots: none.
- AI image generation: none.
- Private source code published: no.
