# FDTD Microwave Resonator Ringdown Provenance

This public diagnostic visualization was generated from numerical FDTD field data for a microwave resonator geometry relevant to RF and quantum hardware workflow direction.

Companion explanation: [FDTD microwave resonator explanation](fdtd_microwave_resonator_explanation.md).

## Numerical Model

- Solver or model family: 2D FDTD TMz diagnostic.
- Field components: Ez, Hx, and Hy.
- Rendered quantities: signed Ez field, probe Ez trace, and cavity field energy.
- Source type: Gaussian-windowed sinusoidal pulse launched from the feed side.
- Boundary handling: graded-loss edge absorber. No CPML claim is made.

## Geometry

The visualization uses a line-coupled rectangular microwave resonator geometry with PEC-like resonator walls, a feed region, a coupling slot, and a central post. The geometry is intended for public diagnostic visualization of field build-up and ringdown behavior in a microwave resonator setting.

## Claim Boundary

The visualization is a solver generated diagnostic communication asset. It is not validation evidence, not a production readiness claim, and not a commercial solver equivalence claim.

It is not a qubit simulation. It does not model Josephson junctions, Hamiltonian extraction, coherence times, cryogenic device behavior, or quantum processor behavior.

No external images were used. No screenshots were used. No AI image generation was used. No private solver source code is published.
