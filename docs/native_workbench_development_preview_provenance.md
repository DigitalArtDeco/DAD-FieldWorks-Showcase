## Public artifact

These four application screenshots were captured by a human from a running DAD FieldWorks native Windows R&D prototype. The prototype uses a native C++/wxWidgets Workbench with embedded VTK scientific visualization. The screenshots publish the complete application window as a bounded development preview; they do not publish private solver source code.

The scientific field views display synthetic visualization fixtures. The PCB cross-section displays a DAD-owned parametric demo model. The Engineering Report demonstrates claim-aware analytical reference reporting, including conservative validation and production flags and explicit model limitations.

No employer or customer data is shown. No private repository path, Windows username, credential, private URL, email content, unpublished measurement data, license key or private source code is shown.

## Public-safety decision

No pixel redaction or crop was required. The two 64-character identity values in the Engineering Report are non-personal, content-style demo identities. Their surrounding visible context identifies an unsaved DAD microstrip demo workflow, uses `mat-*-demo` material names, limits the model to an explicit zero-thickness analytical reference, keeps external validation and production authorization false, and exposes the synthetic visualization fixture status. The values contain no person, employer, customer, filesystem, network, repository or credential information.

The visible `SYNTHETIC VISUALIZATION FIXTURE`, `INTERNAL ONLY`, `Externally validated: false` and `Production allowed: false` labels remain intact. Model names, reference impedance, technical limitations, field values, units, geometry, colorbars and vector directions are unchanged.

## Derivative method and metadata

The public derivatives were losslessly re-encoded locally with Pillow 12.2.0 using PNG compression level 9. No image was resized, upscaled, cropped, annotated or color-converted. Each derivative preserves its source RGBA8 pixels exactly; decoded source and derivative pixel SHA-256 values match for every mapping.

The source PNGs contained no EXIF, text, ICC, time or thumbnail chunks. Their only ancillary chunks were `sRGB`, `gAMA` and `pHYs`. Re-encoding omitted all ancillary metadata, including the unneeded physical-resolution record. Each public derivative contains only `IHDR`, one or more `IDAT` chunks and `IEND`; Pillow reports an empty metadata dictionary and zero EXIF entries for every derivative.

External source images: none. AI image generation: none. Private source code copied: no.

The machine-readable dimensions, byte counts, SHA-256 identities, captions, alt text and claim flags are recorded in the [Native Workbench Screenshot Manifest](../assets/screenshots/native_workbench_preview/manifest.json).
