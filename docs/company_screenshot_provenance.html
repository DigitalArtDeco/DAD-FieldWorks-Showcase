The 3D crop removes the private project path and unrelated desktop areas. It retains the complete displayed geometry, viewer controls and development labels. The other captures contain no visible personal paths.

All five PNGs preserve the selected source pixels exactly. No resampling, smoothing, recoloring, retouching or compositing was used. Original files remain unchanged and are not copied into this repository.

The manifest records original and derivative SHA-256 identities, dimensions, crops, RGBA pixel hashes, captions and uses. The selection recipe can be processed with scripts/prepare_company_screenshots.py. The offline website validator pins both current and retained historical image identities.

Interpretation

Tuto documents construction, not a successful simulation. The sketcher reports unevaluated constraints and no results. Via Transition is a separate result example.

The Cartesian view uses linear magnitude. The Smith view selects S(2,2) at 2.800 GHz. The field view is signed H_z in A/m at saved step 12288, time 3.071875e-09 s, on Z slice 16. It is not a field at either plot's marker frequency.

Development preview. External validation is not yet complete. Not released for production use. See the technical boundaries.
