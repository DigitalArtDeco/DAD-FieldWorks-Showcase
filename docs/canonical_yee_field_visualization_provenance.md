They show progressively later saved states of the same Canonical-Yee electric-field result on a Z-oriented slice, rendered with the same quantitative V/m scale and PCB geometry.

## Publication method

Each source PNG was decoded and losslessly re-encoded with ancillary metadata omitted. Native dimensions and decoded RGBA pixels were preserved exactly. Scientific labels, field distribution, color scale, units, frame identity and values remain unchanged. The public files contain only the required PNG `IHDR`, `IDAT` and `IEND` chunks.

No crop, resize, annotation, color conversion, AI enhancement or reconstruction was applied.
